Fertige Datei

Dieser Text ersetzt den kompletten Inhalt von gaststaetten.yaml.
Kopiert!
  1. Text oben kopieren.
  2. Im GitHub-Repository die Datei gaststaetten.yaml öffnen.
  3. Oben rechts auf das Stift-Symbol klicken.
  4. Gesamten Inhalt markieren (Strg+A) und löschen, dann den kopierten Text einfügen.
  5. Oben rechts auf „Commit changes…“ klicken und bestätigen.
  6. Unter „Actions“ optional „Run workflow“ starten, damit die Karte sofort aktualisiert wird.
