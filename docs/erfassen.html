Speichern einrichten

Einmal pro Gerät nötig. Der Zugangsschlüssel bleibt nur in diesem Browser gespeichert. Richtet das nur auf euren eigenen Geräten ein.
Zugangsschlüssel eintragen
  1. Bei GitHub angemeldet diese Seite öffnen (Settings → Developer settings → Fine-grained tokens → Generate new token).
  2. Name z. B. „Gaststätten pflegen“, Ablaufdatum nach Wunsch (z. B. 1 Jahr).
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write. Sonst nichts.
  5. „Generate token“, den angezeigten Schlüssel kopieren und hier einfügen.
Ohne Zugangsschlüssel: Text kopieren und selbst einfügen
Kopiert
  1. Bei GitHub die Datei gaststaetten.yaml öffnen, Stift-Symbol klicken.
  2. Alles markieren (Strg+A), löschen, kopierten Text einfügen, „Commit changes…“.
