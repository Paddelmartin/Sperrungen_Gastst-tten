Kartenposition festlegen

Oben bei einer Sperrung auf „Position einzeichnen“ oder „Position bearbeiten“ tippen, oder unten eine Regel aus der Liste bearbeiten.
Muss im Feld „Gewässer“ der LBV-Seite vorkommen (Groß-/Kleinschreibung egal).
Ein Wort aus dem Feld „Bereich“, z. B. „Wehrkanal“. Dann gilt die Position nur für diese Stelle. Leer lassen = gilt für jede Sperrung auf diesem Gewässer.
Alle Regeln anzeigen (0)

Speichern einrichten

Wer auf „Gaststätten pflegen“ schon eingerichtet ist, muss hier nichts tun – der Schlüssel gilt für beide Seiten.
Zugangsschlüssel eintragen
  1. Bei GitHub einen Fine-grained token anlegen.
  2. Repository access: Only select repositories → .
  3. Permissions → Contents: Read and write. Sonst nichts.
  4. Schlüssel kopieren und hier einfügen.
